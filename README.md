# WIRE-P: wavelet activations for SEIR physics-informed neural networks

Code and results for the revised manuscript *"WIRE-P: A Phase-Coupled Wavelet Activation for SEIR Physics-Informed Neural Networks"*.

One script runs every experiment in the paper, and a second regenerates every table, figure and statistical test from the stored per-run results.

## Contents

| Path | What it is |
|---|---|
| `wirep/core.py` | Activations (WIRE-P, WIRE-P-A, WIRE-P(φ=0), MV-Morlet, MV-Morlet-A, MV-Morlet+, tanh, ReLU, sigmoid, SIREN, Fourier features), the PINN, residual loss, CWAC collocation, training schedule and evaluation |
| `wirep/data.py` | Real data: 1978 English boarding-school influenza outbreak |
| `wirep/jobs.py` | Set-up of the forward, inverse and real-data problems and of one training run |
| `wirep/experiments.py` | The full experiment matrix: 1,295 runs, 10 seeds |
| `wirep/worker.py` | Worker that claims and runs jobs; many workers (GPU and CPU) can share one queue |
| `run_all.sh` | Runs the whole study: 8 GPU workers and 4 CPU workers |
| `analyze.py` | Builds `results/REPORT.md`, `results/tables/*.tex` and `results/figs/*.png` from the results |
| `tests/test_admissibility.py` | Checks the closed-form mean of WIRE-P and that WIRE-P-A and MV-Morlet-A are exactly zero-mean |
| `results/` | One `.json` (metrics, learned rates, settings) and one `.npz` (loss history, predicted trajectories) per run |

## Experiments

| ID | Setting | Runs |
|---|---|---|
| E0 | Original configuration with the original (detached) L-BFGS gradient, 5 original seeds | 45 |
| E1 | Forward benchmark, 11 activations × 3 diseases × 10 seeds | 330 |
| E2 | Forward benchmark with 2 % and 5 % multiplicative noise on the anchors | 240 |
| E3 | Smaller network, 3 × 32 | 120 |
| E4 | Inverse problem: only I(t) observed every 2 days (0/5/10 % noise); β and γ learned | 450 |
| E5 | Real data, 1978 boarding school: β, σ, γ learned from days 1–10; days 11–14 forecast | 110 |

## Requirements

Python ≥ 3.10, PyTorch ≥ 2.0, NumPy, SciPy, pandas, Matplotlib (`pip install -r requirements.txt`). All computations use float64. A CUDA GPU is recommended. The study took about 3 days on one RTX 4500 Ada (12 concurrent GPU runs) plus a 24-core CPU.

## Usage

```bash
# run everything; finished runs are skipped, so this can be restarted at any time
bash run_all.sh                       # or a single worker: python -m wirep.worker --device cuda
python -m wirep.worker --device cuda --only E1_main   # one experiment only

# tables, figures, statistics -> results/REPORT.md, results/tables, results/figs
python analyze.py

# unit test of the admissibility formulas
python -m pytest tests
```

If workers were killed, delete `results/_locks` before restarting.

## Notes on the revision

- **Admissibility.** WIRE-P is *not* zero-mean. Its integral is cos φ · κ(ω, α, p) · M(α, p) > 0. WIRE-P-A and MV-Morlet-A subtract the mean and are exactly admissible.
- **L-BFGS gradient.** The original notebooks computed du/dτ with `create_graph=False` in the L-BFGS closure, so the L-BFGS gradient omitted the derivative term of the residual. This is corrected; `legacy=True` (experiment E0) reproduces the original behaviour.
- **Statistics.** Exact two-sided Wilcoxon signed-rank tests, paired by seed. They are Holm-corrected within each disease × metric family, and `p_w_holm_all` in the CSV files gives the correction over the whole table.

## Data

The boarding-school counts are from *Influenza in a boarding school*, BMJ 1978;1:587 (also distributed as `influenza_england_1978_school` in the R package `outbreaks`).

## Raw per-run results

The repository contains the summary results (`results/all_results.csv`, `results/REPORT.md`, `results/tables/`, `results/figs/`). The raw per-run files (one `.json` and one `.npz` for each of the 1,295 runs, about 110 MB) are attached to the latest GitHub release as `wirep_raw_results.zip`. To regenerate every table, figure and test from them, unzip into `results/` and run `python analyze.py`.

## Data availability

- Forward and inverse problems use synthetic data generated by the code: the reference SEIR solution (`scipy.integrate.odeint`, rtol = atol = 1e-13) at the parameters in Table 2 of the paper, with multiplicative noise for the noisy settings. No external data are needed.
- The real-data experiment uses the public 1978 boarding-school influenza counts (BMJ 1978;1:587), stored in `wirep/data.py`.
